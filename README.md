# آلة حاسبة ذكية ومتطورة (Smart Arabic Calculator)

تطبيق آلة حاسبة عصري ومتكامل مصمم بأحدث تقنيات الويب، يدعم العمليات الحسابية القياسية والعلمية، مع محول وحدات شامل وسجل حسابات ذكي، ويدعم كامل اختصارات لوحة المفاتيح وتأثيرات صوتية تفاعلية.

## المميزات الرئيسية (Features)

1. **الوضع القياسي والعلمي (Standard & Scientific Modes):**
   - العمليات الأساسية: الجمع، الطرح، الضرب، القسمة، النسب المئوية.
   - العمليات المتقدمة: الجذور التربيعية والتكعيبية، الأسس، العاملي (Factorial `n!`).
   - الدوال المثلثية: `sin`, `cos`, `tan`, `asin`, `acos`, `atan` مع دعم التبديل بين الدرجات والراديان (DEG / RAD).
   - اللوغاريتمات: اللوغاريتم الطبيعي (`ln`) واللوغاريتم العشري (`log`).
   - الثوابت الرياضية: $\pi$ و $e$.

2. **محول الوحدات المدمج (Unit Converter):**
   - الطول والمسافات (متر، كيلومتر، سنتيمتر، بوصة، قدم، ياردا، ميل).
   - الوزن والكتلة (كيلوغرام، غرام، رطل، أونصة، طن).
   - البيانات الرقمية (بايت، كيلوبايت، ميغابايت، غيغابايت، تيرابايت).
   - درجات الحرارة (مئوية، فهرنهايت، كلفن).

3. **ذاكرة الآلة الحاسبة (Memory Features):**
   - وظائف `MC`, `MR`, `M+`, `M-`, `MS` لتخزين واسترجاع القيم أثناء الحساب.

4. **سجل العمليات الحسابية (History):**
   - حفظ تلقائي للعمليات السابقة مع التاريخ والوقت في الذاكرة المحلية (`localStorage`).
   - إمكانية إعادة استخدام أي عملية أو مسح السجل كاملاً.

5. **معاينة حية ومباشرة للنتائج (Live Calculation Preview):**
   - ظهور النتيجة التقريبية أثناء كتابة المعادلة الرياضية قبل الضغط على يساوي (`=`).

6. **مؤثرات صوتية ونسخ سريع:**
   - أصوات نقر ونغمات لطيفة باستخدام Web Audio API بدون الحاجة لتحميل ملفات صوت خارجية.
   - زر نسخ النتيجة للحافظة بنقرة واحدة.

7. **دعم كامل للوحة المفاتيح:**
   - الأرقام: `0-9`
   - العمليات: `+`, `-`, `*`, `/`, `%`, `^`
   - الحساب: `Enter` أو `=`
   - الحذف: `Backspace`
   - المسح الشامل: `Escape`

## طريقة التشغيل محلياً (Run Locally)

### المتطلبات:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### الخطوات:

1. تثبيت الحزم والمكتبات:
```bash
npm install
```

2. تشغيل السيرفر المحلي في وضع التطوير:
```bash
npm run dev
```

3. افتح المتصفح على الرابط الظاهر في التيرمينال (عادةً `http://localhost:3000`).

4. لبناء نسخة الإنتاج الجاهزة للنشر:
```bash
npm run build
```
